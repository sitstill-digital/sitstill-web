## Overview

The **SitStill Digital Archive** is a free, open-source knowledge and media repository dedicated to **Do-Nothing Farming (Natural Farming)**, **The Freedom Engine** framework (available in English and Tamil), and authentic, cryptographically signed visual documentation.

All published resources are shared openly with the global community without paywalls, tracking, or restrictive DRM.

---

## Repository & Release Architecture

To keep the static website fast and accessible on both desktop broadband and mobile data connections, this project separates lightweight web code from large media bundles:

* **Static Web Frontend (`master` branch):** Flat HTML, CSS, JavaScript, and client-side search powered by **Pagefind**.
* **C2PA-Signed Media Volumes (`GitHub Releases`):** High-resolution visuals and bilingual packages are split into standalone **~90 MB ZIP volumes** (plus a complete archive bundle) under the [Releases](../../releases) tab for fast, direct downloads.
* **Lightweight Online Previews:** Web-optimized thumbnails and sample galleries are hosted externally so visitors can inspect visuals before downloading full archives.

## Downloading the Archive Volumes

Visit the **[Releases](../../releases)** section of this repository or the **Shop / Archive** page on our live website to download individual standalone ZIP packs (`Vol 01` – `Vol 07`, ~90 MB each) or the complete 592 MB archive.

Each ZIP volume extracts independently—no multi-part archive tools are required.

## C2PA Authenticity & Verification

Every visual asset distributed in our official releases is cryptographically signed using the **Coalition for Content Provenance and Authenticity (C2PA)** open standard prior to packaging.

* **Tamper-Evident Provenance:** Embedded C2PA manifests verify that images and documents originate from the SitStill Digital Archive and have not been altered.
* **How to Verify:** Download any file from our Release volumes and inspect its cryptographic signature using our **C2PA Verification** guide or any standard C2PA Content Credentials verifier (such as `c2patool` or [Content Credentials Verify](https://contentcredentials.org)).
